## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Open on a phone

Start the backend and client on the same computer, connect the phone to the same Wi-Fi network, and find the computer's local IP address:

```bash
# macOS
ipconfig getifaddr en0
```

Then open `http://<computer-ip>:3000` on the phone. The Next.js development server listens on the local network and proxies `/api/v1` requests to the backend on port `8080`.

If the page cannot be opened, allow incoming connections for Node.js and Java in the macOS firewall. GitHub login also needs an OAuth callback URL configured for the address you use on the phone.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
